Web Trigger Example

This is a simple web trigger test app for Atlassian Forge.

Getting Started

  1. Deploy the app: forge deploy
  2. Get the webhook URL: forge webtrigger info example
  3. Test with curl or the provided test script

Test Endpoint

The webtrigger endpoint handles GET and POST requests at the example key.

Supported Methods:

  • GET - Returns a simple success message
  • POST - Echoes back the request body
  • Other methods - Returns 405 Method Not Allowed

View Logs

To see real-time logs from your function:

forge logs -f my-function
